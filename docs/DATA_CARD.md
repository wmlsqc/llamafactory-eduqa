# 数据说明

原始数据来自本仓库的上游 [shj-cfl/EDU-QA](https://github.com/shj-cfl/EDU-QA)，保留于 `EDU-QA/data`。本项目不将这些问答宣称为自行标注或专家审核的教材数据。

| 文件 | 样本量 | 用途 |
|---|---:|---|
| science_ft_500.jsonl | 500 | 理科指令问答，经处理后划分训练/验证 |
| test.jsonl | 50 | 独立测试，保持与训练/验证隔离 |

每行包含 `instruction`、`input`、`output`。默认流程进行 NFKC、换行和首尾空白归一化，再按“指令 + 输入”查重；相同问题对应不同答案时拒绝继续。检查训练源与测试源是否存在规范化 prompt 重合，固定 seed 42 后划为 450/50/50。

`artifacts/data/manifest.json` 记录源文件哈希、格式检查、空白行计数、去重数量、划分参数及各输出文件 SHA-256。训练入口验证这些哈希，避免数据改变后仍沿用旧记录。

当前检查覆盖格式和规范化重复，不等于语义去重或学科正确性审核。参考答案可能简短、偏向术语罗列；样本规模较小，测试集不能支持大范围教学效果结论。正式扩展应记录来源、授权、学科、难度和审核人员，将同来源/同题变体成组划分。

评测用字符 F1、ROUGE-L 和归一化精确匹配，同时导出人工评分表。涉及数学符号、单位、条件遗漏和推导错误时以人工核验为准。不得只凭文本指标宣布学生学习效果提升。
